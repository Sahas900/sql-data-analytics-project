# SQL Data Analytics Project

## 📌 Overview

This project demonstrates an end-to-end **SQL Server data analytics solution** using sales data. It covers data exploration, analysis, transformation, customer and product analysis, performance analysis, segmentation, and analytical reporting.

The project is designed to demonstrate practical **SQL and data analytics skills** through real-world business analysis scenarios.

---

## 🎯 Objectives

- Explore and understand the available datasets
- Analyze customer and product dimensions
- Analyze sales trends and patterns
- Perform magnitude and ranking analysis
- Analyze changes over time
- Perform cumulative analysis
- Evaluate business performance
- Segment customers and products
- Perform part-to-whole analysis
- Create customer and product reports
